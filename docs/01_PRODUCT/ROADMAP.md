# Purpose

This roadmap defines the planned evolution of BLACKOUT from the initial idea to the Version 1.0 release.

It serves as the single source of truth for project progress, milestones, and release planning.

Unlike other documentation, this document is expected to evolve throughout the project's lifecycle.

---

# Development Philosophy

BLACKOUT follows an incremental development approach.

Each phase delivers a complete, reviewable milestone before moving to the next.

The objective is to ship a polished product rather than a feature-complete one.

# Success Definition

Version 1.0 is successful when:

- Overlay activates instantly.
- Underlying applications continue functioning.
- Battery impact remains minimal.
- Interface requires no explanation.
- Users describe BLACKOUT as clean, fast, and reliable.

---

# Roadmap Rules

The roadmap follows these principles:

- Quality over speed.
- Product decisions before implementation.
- Design before development.
- Simplicity over feature count.
- Stability before release.
